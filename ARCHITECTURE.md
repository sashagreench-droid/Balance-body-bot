# Архитектура MVP

Telegram → bot.py → SQLite

Слои:
- `bot.py` — Telegram handlers, состояния и интерфейс.
- `content.py` — 49 дней, уровни, бейджи, раздел перекусов.
- `db.py` — пользователи, дни, ответы, фото, вопросы, достижения.
- `bot.sqlite3` — создается автоматически при первом запуске.
