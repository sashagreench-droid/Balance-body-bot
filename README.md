# Telegram-бот «49 дней → самостоятельность»

MVP-версия Telegram-бота на Python + python-telegram-bot + SQLite.

## Что уже реализовано

- регистрация пользователя;
- 49 последовательных дней;
- 5 уровней;
- задания и рефлексия;
- XP;
- достижения;
- карта курса;
- мои навыки;
- мой прогресс;
- «Моя система»;
- фотоотчёты;
- вопросы тренеру;
- контрольные точки;
- финальный квест;
- ежедневное напоминание;
- SQLite без отдельной БД;
- защита от повторного начисления XP.

## Запуск

1. Установить Python 3.11+.
2. Создать виртуальное окружение:
   `python -m venv .venv`
3. Активировать его.
4. Установить зависимости:
   `pip install -r requirements.txt`
5. Скопировать `.env.example` в `.env`.
6. Создать Telegram-бота через @BotFather и вставить токен в `BOT_TOKEN`.
7. В `ADMIN_IDS` указать Telegram ID тренера/администраторов через запятую.
8. При необходимости изменить `BOT_TIMEZONE` и `DAILY_REMINDER_HOUR`.
9. Запустить:
   `python bot.py`

## Важно

Это MVP, а не готовый production-сервис. Перед запуском реальных клиентов нужно:
- вынести весь контент в админ-панель/CMS;
- добавить резервное копирование БД;
- настроить защищённый хостинг;
- определить политику хранения фото;
- финально утвердить тексты интерактивов и критерии контрольных;
- отдельно протестировать Telegram UI на iOS/Android.

Токен бота никому не отправляйте и не храните в Git.
